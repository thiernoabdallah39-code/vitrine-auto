# 🖼️ Dossier Images

Place ici tes photos de voitures !

## Nommage recommandé
- `voiture-1.jpg`, `voiture-2.jpg`, etc.
- `about.jpg` pour la photo de la section "À propos"

## Format recommandé
- **Format** : JPG ou WebP
- **Dimensions** : 1200 x 750 px (ratio 16/10)
- **Poids** : moins de 300 Ko par image

## Astuce
Si aucune image n'est présente, un placeholder bleu s'affichera automatiquement.
